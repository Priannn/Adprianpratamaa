Portfolio Deby

HTML

Tailwind

Ringkasan Proyek

Deby Portfolio adalah personal portfolio website yang dibuat untuk menampilkan profil, kemampuan, pengalaman, dan berbagai project yang telah dikerjakan oleh Deby sebagai mahasiswa Bisnis Digital. Website ini dirancang sebagai media personal branding sekaligus sebagai tempat untuk showcase project digital yang pernah dikerjakan.

Tantangan

Portfolio perlu mampu menyampaikan informasi mengenai seseorang secara singkat tetapi tetap menarik secara visual. Tantangannya adalah bagaimana menggabungkan informasi personal, skills, project, dan visual content ke dalam satu website dengan struktur yang mudah dinavigasi tanpa membuat halaman terasa penuh.

Solusi

Saya membuat website portfolio dengan pendekatan visual yang lebih modern dan minimalis. Informasi disusun ke dalam beberapa section agar pengunjung dapat memahami profil dan project secara bertahap. Setiap project juga dibuat agar dapat memiliki halaman detail tersendiri sehingga pengunjung dapat melihat informasi project dengan lebih lengkap.

Project Showcase

Portfolio ini menampilkan beberapa project yang berkaitan dengan digital business dan digital marketing, di antaranya:

  • Kedai Mamitha — pembuatan website dan pengelolaan Instagram.
  • Dwi Yadnya — pengembangan konten Instagram dan TikTok untuk meningkatkan awareness.
  • Arunika Pettisiere — pembuatan website untuk bisnis bakery dengan integrasi chatbot.

Output

Website menjadi media personal branding yang dapat digunakan untuk memperkenalkan profil, skills, serta project secara lebih profesional dan terstruktur.
